# Customer_Behavior_Analysis
Data Analytics project showcasing the customer behavior analysis using python , power Bi and sql.

# Overview
An end-to-end project to analyze data, identify trends, and generate actionable insights.

#Tools
Python : Pandas, NumPy, Matplotlib, Seaborn
SQL :PostgreSQL / MySQL / SQL Server
Power BI :Dashboard creation

#Workflow
Load and explore the dataset using Python.
Perform EDA and clean data.
Run SQL queries to analyze data.
Build an interactive Power BI dashboard.

#How to Run
Clone the repository.
Install dependencies.
Run the Jupyter Notebook.
Execute SQL queries and open the Power BI dashboard.
